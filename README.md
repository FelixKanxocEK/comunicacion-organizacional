# Comunicar para transformar

Blog académico de comunicación organizacional (Actividad 2 de maestría).

## Sitio web

https://felixkanxocek.github.io/comunicacion-organizacional/

**Atención:** esta URL será pública únicamente después de habilitar GitHub Pages en **Settings → Pages → Build and deployment → Deploy from a branch → main → /(root) → Save**.

Incluye tres entradas, seis ilustraciones SVG, seis inserciones de vídeo de YouTube (algunos repetidos) y referencias académicas APA.

Las cinco opiniones de la actividad deben recopilarse de personas reales. La activación del sitio no publica automáticamente el blog en redes sociales.
